# Dweep Shishodia — Systems Studio portfolio

Personal portfolio for AI / ML engineering, freelance projects, roles, and internships.
Plain HTML, CSS, and JavaScript. No install or build step, and no runtime library dependencies.

## Preview locally

Run `python -m http.server 8765 --directory D:/Portfolio`, then open http://127.0.0.1:8765/.

## Files

- `index.html`: the approved Systems Studio portfolio and inline project data.
- `styles.css`, `refinements.css`, `evidence.css`, `model-map.css`: visual design and responsive layouts.
- `production.css`: progressive enhancement fallbacks.
- `app.js`: navigation, motion controls, case studies, and Paleskies pipeline.
- `model-map.js`: the nine-project interactive ML / DL collection.
- `assets/img/`: retained image and social preview assets.
- `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`: GitHub Pages and discovery configuration.

The custom domain is `dweep.me`. The intended Pages source is the dweepCodes repository's `master` branch.
This replacement does not commit or push changes automatically.

Check phone and desktop layouts, keyboard navigation, case-study dialogs, model map/list/filter controls,
reduced motion, and JavaScript-disabled content before publishing future changes.
